# 48. 旋转图像：动画规格

## 数据结构与布局

- 主结构：固定网格矩阵；每个单元格的语义 ID 为 `main-{row}-{col}`，坐标为 `x = originX + col × 64`、`y = originY + row × 64`。
- 辅助结构：额外矩阵以 `aux-{row}-{col}` 标识，位于主矩阵右侧 120px；仅辅助数组解法显示。
- 摄像机：SVG 使用固定中心原点；缩放/平移独立作用于 `.camera-layer`，跨步骤保持视口位置。

## 可观察状态与步骤语义

- 状态：单元格值、源/目标/临时/已完成焦点、辅助数组内容、算法变量与当前代码行。
- 步骤由已有算法快照生成；操作含初始化、读取、复制、交换、赋值和完成。每步描述依据当前值和索引说明对应矩阵变换。
- 焦点：当前数据来源/目标单元格；辅助数组使用 source/target，高亮数不超过当前所执行的赋值或交换操作。
- 稳定元素：所有单元格在每个矩阵解法内保持相同 ID；更新采用 D3 keyed data join，矩阵结构分为箭头、节点与标签图层。
- 解说：使用现有步骤中的具体动作、坐标和值说明当前快照；样例步骤目前以 description 展示。

## 色彩、动效与交互

- 中性单元格纸白，结构背景为淡青灰网格；源青蓝、目标/完成青绿、临时琥珀、交换珊瑚红。颜色辅以描边、标签和索引，不单靠颜色传递语义。
- 默认 D3 过渡 180ms；系统启用 `prefers-reduced-motion` 时 JS 过渡为 0，CSS 动效降低为近零。跳步时打断同层现有过渡后以当前位置继续。
- 支持鼠标拖动平移、滚轮与按钮缩放、恢复居中。

## 首屏布局

- 顶栏 48px；输入栏与页签单行紧凑展示；控制栏 48px。
- 工作区使用画布优先布局，桌面端画布在左、代码栏最大 400px；窄屏上下排列并保持单屏。
- 代码、算法变量与步骤描述跟随同一快照更新。
